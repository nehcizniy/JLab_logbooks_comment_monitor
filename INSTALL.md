# Simple Install and Setup Guide

This guide works for Google Chrome and most Chromium-based desktop browsers on macOS, Windows, and Linux.

## Install

1. Download the extension ZIP file.
2. Extract the ZIP file to a folder you will keep. Do not delete or move this folder after installation.
3. Open Chrome and enter `chrome://extensions` in the address bar.
4. Turn on **Developer mode** in the upper-right corner.
5. Select **Load unpacked**.
6. Select the extracted `jlab-logbook-comment-monitor` folder.
7. Select Chrome's Extensions button, then pin **JLab Logbook Comment Monitor** so it is easy to open.

## First-time setup

1. Sign in to the [JLab Logbooks website](https://logbooks.jlab.org/) in Chrome. Keep Chrome running, but you do not need to keep a logbook tab open.
2. Open the extension and follow its setup guide.
3. Choose the logbooks you want to monitor and select a checking interval.
4. Leave the main **Comment monitor** switch on.
5. Choose an interface:
   - **Simple** for the most-used controls.
   - **Large simple** for the same controls with larger text and buttons.
   - **Advanced** for every setting.
   - **Large advanced** for every setting with larger text and buttons.
6. Turn on **Dark mode** if you prefer a darker display. It works with every interface size.
7. Select **Test my setup** and allow Chrome system notifications if asked.

The extension does **not ask for, read, or store your password**. You sign in directly on JLab's website.

## Everyday use

- **Check now** runs an immediate check.
- **Clear alerts** removes current system notifications.
- **Recent alarms** keeps the latest alert history inside the extension.
- **Go to entry** on a notification opens the related logbook entry.
- The extension checks automatically at the selected interval while Chrome is running and the monitor switch is on.

If monitoring stops after an update or browser restart, open the extension, confirm that the main switch and desired logbooks are on, then select **Test my setup**.

## Update or uninstall

- To update, extract the new ZIP over the existing extension folder, open `chrome://extensions`, and select the extension's **Reload** button. Export settings first if you want a backup.
- To uninstall, open `chrome://extensions` and select **Remove**. You can then delete the extracted folder.
