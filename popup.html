Quick help
  • Use the top switch to start or pause automatic checks.
  • Use Check now for an immediate scan.
  • Open Recent alarms to review and reopen the latest alerts.
  • Add public JLab schedule URLs under Shift Crew to see the current Hall A–D workers.
  • Configure each logbook by entry count, hours, or days.
  • Use each logbook's Shift summaries switch to control edit notifications.
  • Turn off DTM recurring reminders to receive only event changes.
  • Email notifications require connecting a Gmail or Microsoft 365 account.
  • Chrome must remain running for scheduled checks.
