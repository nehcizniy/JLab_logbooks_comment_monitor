Quick help
  • Use the top switch to start or pause automatic checks.
  • Switch between Simple, Large simple, Advanced, and Large advanced at any time. Your settings and alarm history are preserved.
  • Use Check now for an immediate scan, New entry to open JLab's entry form, or Logbooks to open the main site.
  • Open Recent alarms to review and reopen the latest alerts.
  • Open Extension updates to check for a new release, update safely, or return to an earlier version.
  • Use Monitoring health to review each source or copy privacy-safe diagnostics.
  • Add public JLab schedule URLs under Shift Crew to see the current Hall A–D workers.
  • Use Alerts to choose system/email delivery, quiet hours, or a temporary snooze.
  • Configure each logbook by entry count, hours, or days.
  • Use each logbook's Shift summaries switch to control edit notifications.
  • Use the DTM tab to review event status, open the live DTM page, or turn recurring reminders on and off.
  • Email is optional. Native system notifications work without an email account.
  • Chrome must remain running for scheduled checks.
