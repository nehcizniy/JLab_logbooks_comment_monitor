Keep your settings

Do not click Remove on Chrome’s extensions page. Reloading this extension with its fixed ID preserves its settings, monitoring history, interface choice, selected tab, and collapsed sections. Export Settings backup first as an extra safety copy.

UPDATE

Install the latest version

  1. Select Download latest ZIP and extract it.
  2. Find the folder currently loaded in Chrome and rename it with -backup at the end.
  3. Move the newly extracted folder into the old folder’s location and give it the old folder’s exact name.
  4. Open chrome://extensions and select Reload on JLab Logbook Comment Monitor.
  5. Confirm the installed version shown in the popup and select Test my setup.

ROLL BACK

Return to a previous version

  1. Select See all versions and download the ZIP for the version you want.
  2. Rename the current extension folder so it remains available as a backup.
  3. Put the older folder at the original folder path and restore the original folder name.
  4. Open chrome://extensions and select Reload.
  5. If settings look wrong, import the backup you exported before changing versions.

Keep at least one known-working ZIP or backup folder. Older versions may not understand settings introduced by a newer release, which is why exporting settings first is recommended.
